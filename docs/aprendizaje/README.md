## Plantilla

Usar la plantilla en `template-fase.md` para nuevos archivos.

## Contenido por Archivo

Cada archivo debe contener:
- **Objetivos** — Qué se logra en esta fase
- **Tareas completadas** — Lista con fecha y archivos afectados
- **Decisiones** — Qué se decidió y por qué
- **Problemas** — Qué salió mal y cómo se resolvió
- **Aprendizajes** — Conceptos C#/.NET/Linux aprendidos
- **Métricas** — Tests escritos, cobertura, archivos creados
