# Extras — Temas opcionales

Contenido de aprendizaje **opcional**, fuera del scope de cualquier fase. Los extras existen para explorar
temas valiosos que no bloquean el avance del proyecto: podés leerlos, practicarlos o ignorarlos sin
consecuencias.

## Reglas de los extras

- **No pertenecen a ninguna fase**: no aparecen en `docs/phase-plan.md` ni en sus criterios de salida.
- **Nunca bloquean una fase**: una fase se cierra sin haber tocado un extra.
- **No son la ruta principal**: la ruta principal vive en `docs/phase-plan.md` y `docs/learning/`.
