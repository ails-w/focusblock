## Plantilla

Usar `template-phase.md` para cada fase nueva. Cada concepto tiene: Qué es / Qué problema resuelve / Para qué sirve en este proyecto / Cómo se usa / Error común / Referencias.

## Contenido por Archivo

- `phase-NN-name.md` — conceptos de la fase en formato plantilla.

## Reglas

- Se acumula: los conceptos aprendidos NUNCA se borran.
- Se escribe durante la fase, no al final (aprendizaje justo-a-tiempo).
- Cada concepto debe tener su "Error común" — es lo que demuestra comprensión real.
